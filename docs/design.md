# Sort Party: agreed design (2026-10-24)

- Like Sortime (Talefun). For kids; minimal reading; touch drag; 2D art drawn in code; sound effects with mute, no music.
- Level types mixed on one numbered path:
  - Shelf: 3 slots a shelf, three of a kind in the front row clear, rows behind move up; won when all shelves are empty.
  - Dogs: line of dogs, front one to the bowl of its coat colour; bowls hold 3 and are swapped when full; wrong colour bounces.
  - Room: big scrolling room, each thing to its home; wrong home bounces; won when the floor is clear.
- Timer on every level (longer for rooms). Out of time: try again, no penalty. 1-3 stars by time left. Any finish unlocks the next.
- Players pick a picture; progress per picture, saved on the device. Sync between devices (private repo + token) only if needed.
- Harder over time: more kinds, shelves, coats (two-tone from about level 10), bigger rooms, tighter timers.
- Hosted on GitHub Pages, public repo, no login.
